How it was built

Three days, one laptop. What was easy, what was hard.

Prove the toolchainONNX Runtime QNN on ARM64 Python, AI Hub, GenieX. Found the silent CPU fallback and fixed it in npu.py before writing a line of product.
Face, then cursorAI Hub export, Qualcomm's MediaPipe pipeline re-done in numpy, head pose and blink metrics; joystick mapping, dwell ring, gestures, calibration.
Speech, then brainPrecompiled Whisper with a KV-cache decode loop; two-tier commands; Qwen3-4B with a strict tool schema and a UI Automation snapshot.
Narrator, app, deploymentQwen3-VL, Piper in English and Hindi, overlay, tray, hotkeys, logging, installer, model fetcher, benchmark suite, Arduino bridge.

Easy

Qualcomm AI Hub. Every model compiled and profiled on real X2 Elite and X Elite devices in minutes, with per-op compute-unit reports. GenieX made the language and vision models a pip install and one pull, on the NPU first try.

Hard

Windows ARM64 plumbing. No OpenCV wheel, so the camera goes through DirectShow COM. Piper's espeak bridge is not built for ARM64. QNN context caches must be reused, not regenerated. Two GenieX models cannot load at the same moment. And the QNN provider must be chosen through the new device API, or ONNX Runtime quietly runs on the CPU while reporting nothing.
