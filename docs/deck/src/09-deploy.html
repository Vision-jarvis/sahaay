08 · Deployment and accessibility

One command installs it on any Snapdragon X or X2 PC. After that it never needs the internet.

# HP OmniBook, EliteBook, any Snapdragon X / X2 PC · no admin rights
powershell -ExecutionPolicy Bypass -File install.ps1
# Python if missing · venv · models for your chipset, once · espeak-ng · Start Menu shortcut
Private

No account, no cloud, no telemetry

Camera frames, audio and screenshots are processed in RAM and discarded. Zero network calls at runtime; verifiable by running with Wi-Fi off. A local log file for support, nothing else written.

Fits the judge's laptop

16 GB for hands-free mode, 32 GB for everything

Measured process growth: language model 5.4 GB, vision model 6.1 GB. On a 16 GB OmniBook 3 or 5 run with --no-vlm or the 2B vision model; on a 32 GB OmniBook X or Ultra load both. 45 TOPS is enough.

Accessible

Usable without sight or hands

Global hotkeys, a tray icon, a heads-up panel showing what was heard and done with live per-model latency, spoken confirmation of every action, English and Hindi voices, and switch access through any Arduino, including the UNO Q from the AI Lab kit.
